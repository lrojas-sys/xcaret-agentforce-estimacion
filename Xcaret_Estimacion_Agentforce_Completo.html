4. Consumo de Data Service Credits

Aplicable a HU63 — Validar autenticación consultando el Unified Profile.
Cuando el agente consulta el Unified Profile para validar la identidad del cliente durante la conversación, esto consume el usage type Data Queries de Data 360 — es una consulta "pull" a demanda, no un proceso continuo/streaming, ya que solo se dispara cuando el cliente lo solicita.

Tipo de consumo Costo unitario Cuándo se dispara Nota clave
Data QueriesiPara validar la identidad de un cliente hay dos opciones: Agentforce nativo, donde una Acción de Agente (Flow Autolaunched o Apex) consulta directamente el objeto Contact en el CRM transaccional y factura solo Flex Credits (ej. 20 créditos por acción), ideal cuando el dato ya vive en el CRM; o Data Cloud Identity Resolution, que factura créditos de Data Cloud Services y conviene cuando se necesita unificar identidades de múltiples fuentes o hacer búsqueda semántica/SQL sobre el lakehouse.
