Estimación de queries por interacción:
  • Path A (camino feliz): 4–6 queries (identidad + perfil + reservas + pickup + detalle + registro)
  • Path B (no localizada): 5–8 queries (incluye reintentos de búsqueda con datos alternativos)
  • Path C (transferencia): 6–9 queries (incluye recuperación de contexto completo para traspaso)

Promedio ponderado: ~5 queries por conversación

Nota: El consumo de queries depende de la implementación. Si las reservas se consultan directamente vía SOQL a Salesforce CRM (en lugar de Data Cloud), el consumo de queries DC podría reducirse a 2–3 por conversación (solo identidad + perfil). Confirmar con el equipo de arquitectura la fuente de datos de reservas y servicios de transporte.

5. Lógica de Consolidación

Acciones consolidadas: La consulta de reservas activas y la verificación de pickup/transporte asociado se pueden ejecutar como un solo Flow (1 acción), reduciendo el conteo total. De igual forma, el registro de trazabilidad (HU 71) puede consolidarse con la última acción del agente si se implementa como un Flow post-conversación.
Queries consolidadas: La resolución de identidad y perfil unificado pueden resolverse en 1 query si el modelo de datos tiene un DMO unificado. La búsqueda de reserva + servicio de transporte asociado puede ser 1 query si existe una relación directa en el modelo.
Oportunidad de optimización: Si se consolidan Flows y queries, el consumo del camino feliz podría reducirse a 5–6 acciones (100–120 créditos) y 3–4 queries. Esto requiere validación con el equipo de implementación.

6. Supuestos para Estimación Ponderada

  • ~70% de conversaciones encuentran reserva con pickup (Path A — camino feliz)
  • ~20% de conversaciones no localizan reserva o no tiene pickup asociado (Path B)
  • ~10% requieren transferencia a ejecutivo humano (Path C)
  • Data Cloud se utiliza para resolución de identidad, perfil unificado y consulta de reservas
  • El agente nunca toma acciones de cambio o cancelación; solo informa
  • No se envían comprobantes ni documentos
  • La información mostrada corresponde únicamente a la reserva autenticada
